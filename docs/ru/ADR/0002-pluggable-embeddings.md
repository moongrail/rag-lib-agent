# ADR 0002 — Подключаемые эмбеддинги

**Статус:** Принято

**Контекст.** Эмбеддинги могут приходить из Ollama, HuggingFace (TEI), OpenAI-совместимого
API или локальной in-process модели. Нельзя привязываться к одному вендору.

**Решение.** Определить `EmbeddingProvider` (наш интерфейс), оборачивающий любую
LangChain4j-модель `EmbeddingModel`. `EmbeddingConfig` выбирает реализацию из
`app.embedding.provider`. `PgVectorEmbeddingStore` создаётся с
`embeddingProvider.dimension()`, чтобы таблица совпадала.

**Последствия.**
- Смена провайдера — одной настройкой, без изменения кода.
- По умолчанию `local` (in-process all-minilm) не требует внешних сервисов — идеально для первого запуска.
- Ограничение: смена размерности требует пересоздания таблицы `rag_embeddings`.
