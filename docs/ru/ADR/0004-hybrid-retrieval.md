# ADR 0004 — Гибридный поиск (вектор + ключевые слова, RRF)

**Статус:** Принято

**Контекст.** Чистый семантический поиск пропускает точные технические термины, коды
ошибок и названия продуктов. Лексический поиск в одиночку не ловит перефразировки.

**Решение.** Использовать pgvector `SearchMode.HYBRID`: косинусное сходство, слитое с
PostgreSQL `tsvector` FTS через Reciprocal Rank Fusion (`rrf-k`, по умолчанию 60).

**Последствия.**
- Лучше recall/precision на терминологичной техдокументации, чем только векторный поиск.
- Гибридный запрос должен передавать и `queryEmbedding`, и исходный текст `query`
  (гарантируется в `DocumentRetrievalService`).
- RRF-оценки ранговые (макс. ≈ 2/(k+1)); `min-score` держим низким.
