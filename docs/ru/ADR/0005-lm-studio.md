# ADR 0005 — LM Studio как локальный провайдер

**Статус:** Принято

**Контекст.** Разработчикам нужна полностью локальная опция (без облачного ключа, без
исходящего трафика) для эмбеддингов и чата при разработке и на изолированных машинах.

**Решение.** LM Studio отдаёт OpenAI-совместимый API (`http://127.0.0.1:1234/v1`). Мы
поддерживаем его как:
- провайдер чата `lmstudio` → `OpenAiChatModel` с базовым URL LM Studio;
- провайдер эмбеддингов `lmstudio` → `OpenAiEmbeddingModel` с базовым URL LM Studio.

**Последствия.**
- Переиспользует существующий OpenAI-совместимый клиент; без новых зависимостей.
- Модель по умолчанию `omnicoder-qwen3.5-9b-claude-4.6-opus-uncensored-v2` (настраивается).
- Требует запущенный локально LM Studio с загруженной моделью; docker-compose его не поднимает.
